# 北海道カーシェア料金比較

三井のカーシェアーズとタイムズカーの料金を計算する、スマホ向けの非公式アプリです。

## GitHub Pagesで公開

1. リポジトリのルートに `index.html`、`carshare.html`、`manifest.webmanifest`、`pwa.js`、`sw.js`、`.nojekyll`、`icons/`、`assets/` をアップロードします。
2. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択します。
3. **main / (root)** を選択して保存します。別のブランチを使う場合はそのブランチを選びます。
4. 表示された **HTTPSの公開URL** をスマホで開きます。

個人のパソコン上の `file://` からはPWAのインストールとサービスワーカーは動作しません。GitHubにアップロードするだけでは公開されず、Pagesの設定が必要です。パスはすべて相対指定なので、リポジトリ名のある `https://ユーザー名.github.io/リポジトリ名/` でも動作します。

## ホーム画面に追加

- **iPhone**：Safariで公開URLを開き、共有 → ホーム画面に追加 → 追加。「Webアプリとして開く」が表示される場合はオンにします。
- **Android**：Chromeで公開URLを開き、アプリ内の「ホーム画面に追加」、またはChromeメニューの「アプリをインストール」「ホーム画面に追加」を使います。
- アプリ内ボタンの表示はブラウザの対応状況と条件によって異なります。
- 初回のオンライン読み込みとオフライン準備の完了後は、電波がなくても料金を計算できます。

## クイック比較と出発時刻

初期画面はクイック比較です。ヤリスクロス・ライズ、SUV、ミニバンから選ぶと両社の料金クラスを自動設定します。SUVは三井ヴェゼル e:HEV／タイムズC-HR、ミニバンは三井ヴォクシー／タイムズノアを比較するため、同一車種ではありません。細かく設定モードでは各社のクラスを個別指定できます。追加補償は両社共通のスイッチです。

「今から」は日本時間の現在時刻で計算し、表示中は1分ごとに更新します。指定日時でも見積もれます。両社とも通常料金・夜間料金を考慮して、出発時刻での最も安い合計を表示します。タイムズでナイトパックが安い場合は、タイムズの予約時にそのメニューを選ぶ必要があります。

「18時まで待つ」は、次の18:00出発で同じ時間・距離・追加補償条件を比較します。返却も待った分だけ後ろにずらします。空き状況の保証はありません。待って安くなる場合と、待っても安くならない場合の両方を表示します。

## 更新

HTML・料金を変更して公開する際は、`sw.js` の `v1` を `v2` などに変更してください。新しいファイルを事前保存した後、アプリ内に「更新する」ボタンが表示されます。料金は2026年10月1日に確認した公式情報に基づき、月会費・無料利用分・特典等は含みません。

ロゴ画像はユーザー提供の原画像を使用した識別用のものです。本アプリは両社の公式アプリではありません。
