# 北海道カーシェア料金比較

三井・タイムズ・オリックスカーシェアの料金を計算する、スマホ向けの非公式アプリです。

## GitHub Pagesで公開

1. ZIPを展開して、中のファイルとフォルダーをすべてリポジトリのルートにアップロードします。`index.html` がリポジトリの直下にあることを確認してください。`map.js`、`controls.js`、`stay.js`、`vendor/`、`assets/` も必要です。
2. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択します。
3. **main / (root)** を選択して保存します。別のブランチを使う場合はそのブランチを選びます。
4. 表示された **HTTPSの公開URL** をスマホで開きます。

個人のパソコン上の `file://` からはPWAのインストールとサービスワーカーは動作しません。GitHubにアップロードするだけでは公開されず、Pagesの設定が必要です。パスはすべて相対指定なので、リポジトリ名のある `https://ユーザー名.github.io/リポジトリ名/` でも動作します。

## ホーム画面に追加

- **iPhone**：Safariで公開URLを開き、共有 → ホーム画面に追加 → 追加。「Webアプリとして開く」が表示される場合はオンにします。
- **Android**：Chromeで公開URLを開き、アプリ内の「ホーム画面に追加」、またはChromeメニューの「アプリをインストール」「ホーム画面に追加」を使います。
- アプリ内ボタンの表示はブラウザの対応状況と条件によって異なります。
- 初回のオンライン読み込みとオフライン準備の完了後は、電波がなくても料金を計算できます。

## クイック比較と出発時刻

初期画面はクイック比較です。ヤリスクロス・ライズ、SUV、ミニバンから選ぶと両社の料金クラスを自動設定します。SUVは三井ヴェゼル e:HEV／タイムズC-HR、ミニバンは三井ヴォクシー／タイムズノアを比較するため、同一車種ではありません。細かく設定モードでは各社のクラスを個別指定できます。追加補償は両社共通のスイッチです。

「今から」は日本時間の現在時刻で計算し、表示中は1分ごとに更新します。指定日時でも見積もれます。両社とも通常料金・夜間料金を考慮して、出発時刻での最も安い合計を表示します。タイムズでナイトパックが安い場合は、タイムズの予約時にそのメニューを選ぶ必要があります。

「18時まで待つ」は、次の18:00出発で同じ時間・距離・追加補償条件を比較します。返却も待った分だけ後ろにずらします。空き状況の保証はありません。待って安くなる場合と、待っても安くならない場合の両方を表示します。

## 更新

HTML・料金を変更して公開する際は、`sw.js` の `v1` を `v2` などに変更してください。新しいファイルを事前保存した後、アプリ内に「更新する」ボタンが表示されます。料金は2026年10月1日に確認した公式情報に基づき、月会費・無料利用分・特典等は含みません。

ロゴ画像はユーザー提供の原画像を使用した識別用のものです。本アプリは両社の公式アプリではありません。


車種写真は assets/cars/ に保存しています。このフォルダーも一緒にアップロードしてください。全21枚をオフライン用キャッシュに含めています。画像の出典URLと対応車種は assets/cars/sources.json に記録しています。


地図入力：map.js、map-config.json、vendor/ フォルダーも一緒に公開します。地図で出発・目的地を選び、道路による往路と復路の距離・運転時間に滞在・余裕時間を足して、共通の料金入力へ反映します。現在地はユーザーがボタンを押した場合のみ取得します。渋滞・天候・有料道路料金は含みません。地図・場所検索・経路計算には通信が必要です。Photon/OSRMの公開サービスは可用性保証がなく、小規模な個人利用向けです。利用者が増える場合はmap-config.jsonでプロバイダーを切り替えてください。地図タイルはオフライン保存しません。

## オリックス追加（2026年10月5日）

最安クラスは3社比較。シエンタ・SUV・大型ミニバンは北海道で確認済みの三井・タイムズを比較し、オリックスは除外理由を表示します。細かく設定では3社のクラスを個別指定できます。比較結果は安い順で、各社をタップすると内訳が開きます。

オリックスは2026年6月以降の新サービス（個人A/U29/個人B）に対応。旧会員料金には対応していません。月額基本料と割引は含みません。通常6時間以内の距離無料と夜間の全距離課金を別々に計算し、合計が安い予約方法を表示。夜間は18時〜翌9時に収まる利用のみ。補償660円/24時間。個人Bミドル12時間は公式に12,980円/12,990円の併記があるため、一覧表の12,980円を使用し画面に注記します。

北海道のノート・フィット・ロッキーは公式ステーション情報を確認。写真はオリックス公式車種一覧より。

# 画像とアイコンの更新

フィット・ノートは公式配布の透過WebPをそのまま採用。JPEG化で失われた透過情報を復元し、黒い背景と段差の見え方を修正。車の形・仕様を変えないことを優先し、AIが車体を描き直した候補は採用していません。

アプリアイコンは内蔵imagegenで編集。通常アイコンとAndroid用maskableアイコンを作成し、32 / 180 / 192 / 512pxへ書き出しました。更新後の画像URLとオフラインキャッシュはv23です。

採用したアイコンの編集指示：三井・タイムズ・オリックスの3社ロゴを同じ大きさのタイルとして三角形に配置。青・黄色・紺色を暖かいアイボリー背景に合わせ、中央に比較の双方向矢印を置く。追加の文字は入れず、小さいホーム画面アイコンでもわかりやすい上品な仕上がりにする。

Android用の追加指示：同じデザインを中央の安全な円形範囲に収め、丸く切り取られてもロゴや文字が欠けない余白を確保する。

旧アイコンがホーム画面に残る場合は、新版をGitHub Pagesにアップロードした後、公開ページの「更新する」を押してください。ホーム画面の画像が変わらない端末では、一度ショートカットを削除して追加し直してください。
